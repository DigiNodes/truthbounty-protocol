# TruthBounty V2 high-fidelity authority prototype

This dependency-free prototype translates the approved UX authority into a responsive visual reference. It is not production application code. Every value shown is illustrative and must never be presented as protocol truth.

## Included views

- claimant dashboard and next-action hierarchy;
- verifier queue and eligibility context;
- bounded admin system overview;
- canonical claim detail hierarchy;
- evidence step of the claim-creation wizard;
- desktop, tablet and mobile compositions;
- light and dark visual tokens;
- explicit boundaries for screens that are specified but not expanded.

Open `index.html` directly in a browser. Use the active-context selector to switch roles. The prototype contains no API, wallet, contract, persistence or analytics integration.
