# TruthBounty Frontend V2 Authority Wireframes

These low-fidelity wireframes define hierarchy and required regions, not final artwork. Implementation must follow the route, role, transaction-state, responsive, and accessibility authority under `docs/ux-authority`.

- [Claimant dashboard](./claimant-dashboard.svg)
- [Verifier dashboard](./verifier-dashboard.svg)
- [Admin dashboard](./admin-dashboard.svg)
- [Claim detail](./claim-detail.svg)

## Interpretation

- Purple marks the primary action or active context.
- Amber marks pending, stale, or attention-required state.
- Green is reserved for confirmed/finalized success.
- Every visual status also requires text and an accessible name.
- On mobile, the sidebar becomes a drawer and multi-column regions stack by the documented priority.
