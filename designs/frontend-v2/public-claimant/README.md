# TruthBounty V2 Public and Claimant Screens

This package is Batch 3 of the approved frontend design program. It consumes the Brand Foundation and Frontend Foundation without redefining protocol authority.

## High-fidelity boards

1. `01-product-landing.svg` — public product entry and live-activity framing.
2. `02-explore-claims.svg` — public search, filters and freshness-labelled results.
3. `03-claim-detail.svg` — canonical claim, evidence, phase, outcome boundary and timeline.
4. `04-wallet-entry-and-eligibility.svg` — progressive wallet entry and fail-closed eligibility.
5. `05-claimant-dashboard.svg` — claimant overview and ordered next actions.
6. `06-submit-claim-statement.svg` — recoverable statement and verification criteria.
7. `07-submit-evidence.svg` — public evidence intake and integrity boundary.
8. `08-submit-funding.svg` — bond, fee, allowance and economic authority.
9. `09-submit-review-authorize.svg` — preflight, review and wallet authorization boundary.
10. `10-owned-claims.svg` — local drafts separated from canonical claims.
11. `11-rewards-transactions.svg` — accrued/claimable/pending/withdrawn values and recovery.

All values, hashes, addresses, balances and activity are illustrative composition data. Production implementations must load canonical values from the pinned release, contracts and labelled API projections.

Run `node generate-public-claimant-boards.mjs` to reproduce the SVG boards.
