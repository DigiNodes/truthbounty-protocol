# TruthBounty brand assets

This directory contains the approved Evidence Shield identity source files.

## Files

- `truthbounty-glyph.svg` — colour glyph on a transparent background.
- `truthbounty-glyph-monochrome.svg` — single-colour glyph using `currentColor`.
- `truthbounty-app-icon.svg` — square rounded application icon on Ink Navy.
- `truthbounty-landscape-dark.svg` — landscape lockup for dark surfaces.
- `truthbounty-landscape-light.svg` — landscape lockup for light surfaces.

The landscape lockups require Geist Sans. Product code should load Geist before rendering them. The glyph files contain no font dependency.

Do not redraw the shield, change its aspect ratio, separate the verification diamond, recolour individual paths, add shadows, or place Bounty Gold inside the core identity.
