# V2-SC-020 — Implement Slashing and Exhaustive Allocation Engine

## Overview

Implement losing-stake calculation and a basis-point allocation engine whose outputs always reconcile.

## Problem Context

Legacy weighted logic can leave part of slashed value without a destination. V2 requires every unit to be allocated to winners, treasury, burn, insurance, fee, or a documented refund.

This issue belongs to **V2-EPIC-SC-001 — Canonical Contract Topology and Deployment**. Existing repository issues are historical only; their titles, labels, closure state, or partial implementations do not satisfy this issue.

## Technical Scope

- Determine slashable principal from final outcome and round participation.
- Allocate each slash pool across configured categories totaling exactly 10,000 basis points.
- Assign integer remainder to the configured deterministic destination.
- Produce typed ledger instructions and StakeSlashed/TreasuryAllocated events.
- Support no-slash inconclusive behavior.

The contributor must begin by auditing current files that overlap this scope. Reusable logic may be retained only when it conforms to the governing V2 interfaces, events, authority boundaries, and tests. The pull request must identify reused, replaced, and deprecated paths.

## Security and Integrity Requirements

- Reject invalid allocation totals and over-slashing.
- Never slash winning principal or unrelated locks.
- Prevent treasury or caller-selected percentages at settlement time.
- Preserve blockchain authority and every applicable protocol invariant.
- Do not add secrets, production credentials, dummy production addresses, backend settlement authority, or Stellar/Freighter runtime dependencies.

## Required Tests

- All-winner, mixed, tie/inconclusive, appeal-changed, and appeal-unchanged tests.
- Fuzz tests proving allocated total equals slashed total.
- Rounding tests for small and indivisible amounts.
- Run the repository’s complete required Hardhat and Foundry suites and report unrelated pre-existing failures separately.
- Add regression coverage for every defect or unsafe legacy behavior removed by this work.
