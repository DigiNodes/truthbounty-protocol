# V2-SC-025 — Implement Reputation Proof and Weight Multiplier Adapter

## Overview

Implement proof verification and freeze the resulting multiplier as part of verification submission.

## Problem Context

Verification weight may use reputation only when the verifier supplies a proof against the frozen approved root and the multiplier remains within encoded bounds.

This issue belongs to **V2-EPIC-SC-001 — Canonical Contract Topology and Deployment**. Existing repository issues are historical only; their titles, labels, closure state, or partial implementations do not satisfy this issue.

## Technical Scope

- Define an adapter interface for approved proof schemes.
- Verify membership/value proof against the round's frozen root.
- Map proof value to a bounded basis-point multiplier using versioned rules.
- Default deterministically to 10,000 basis points when no optional proof is supplied.
- Store the applied multiplier and effective weight with the verification.

The contributor must begin by auditing current files that overlap this scope. Reusable logic may be retained only when it conforms to the governing V2 interfaces, events, authority boundaries, and tests. The pull request must identify reused, replaced, and deprecated paths.

## Security and Integrity Requirements

- Reject forged, expired, wrong-root, replayed-context, or out-of-bound proofs.
- Proof failure must not permit caller-selected multiplier fallback.
- Do not expose unnecessary identity data.
- Preserve blockchain authority and every applicable protocol invariant.
- Do not add secrets, production credentials, dummy production addresses, backend settlement authority, or Stellar/Freighter runtime dependencies.

## Required Tests

- Valid, absent, invalid, expired, and wrong-round proof tests.
- Multiplier bound and rounding fuzz tests.
- Regression test proving backend-provided scores have no effect.
- Run the repository’s complete required Hardhat and Foundry suites and report unrelated pre-existing failures separately.
- Add regression coverage for every defect or unsafe legacy behavior removed by this work.
